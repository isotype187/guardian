# Guardian Migration History

## Toolkit Transition

Toolkit is no longer the canonical project.

Guardian is the active development path.

---

# Direction

Guardian:

- Active project
- Current development location
- Future updates

Toolkit:

- Reference workspace
- Historical assets
- Migration source

---

# Migration Rules

Do not continue major work in Toolkit.

If an asset is needed:

1. Review it.
2. Validate usefulness.
3. Move it into Guardian.
4. Document the migration.

---

# Migration Principle

Toolkit provides history.

Guardian provides the future.
