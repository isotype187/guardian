# ADR-002: Pester v5 to v6 Migration

**ADR Number:** ADR-002  
**Title:** Migration from Pester v5 to Pester v6 Syntax  
**Status:** Accepted  
**Date:** 2026-07-25  
**Authors:** Guardian Engineering Team  
**Reviewers:** Guardian Engineering Team  

---

## Context

The Guardian test suite was originally written for Pester v5 syntax. Pester v6 introduces breaking changes requiring migration.

## Problem Statement

All milestone test files (M1-M10) use deprecated Pester v5 syntax that fails under Pester v6.

## Options Considered

### Option 1: Stay on Pester v5
**Pros:** No migration effort; existing tests work  
**Cons:** v5 is unmaintained; no security updates; blocks modern CI; incompatible with PowerShell 7.4+

### Option 2: Full Migration to Pester v6 (Selected)
**Pros:** Current maintained version; modern syntax; CI compatible; better error messages  
**Cons:** One-time migration effort across all test files

### Option 3: Dual Support (v5 + v6)
**Pros:** Gradual migration  
**Cons:** Complexity; maintenance burden; not sustainable

## Decision

**Selected Option:** Option 2 — Full Migration to Pester v6

## Migration Rules Applied

| v5 Syntax | v6 Syntax | Example |
|-----------|-----------|---------|
| `Should Be` | `Should -Be` | `$x | Should -Be 5` |
| `Should Match` | `Should -Match` | `$x | Should -Match 'pattern'` |
| `Should Throw` | `Should -Throw` | `{...} | Should -Throw` |
| `Should BeNullOrEmpty` | `Should -BeNullOrEmpty` | `$x | Should -BeNullOrEmpty` |
| `BeforeAll`/`AfterAll` | Same (case-sensitive) | `BeforeAll { ... }` |
| `BeforeEach`/`AfterEach` | Same (case-sensitive) | `BeforeEach { ... }` |

## Consequences

### Positive
- All 14 Foundation + 25 M2 + 35 M3 + 28 M4 + 11 M5 + 11 M6 + 17 M7 + 18 M8 + 10 M9 + 34 M10 = **203 tests** now pass on Pester v6
- Modern CI compatible
- Better error messages and debugging

### Negative
- One-time migration effort (~4 hours across sessions)
- Must maintain v6 syntax discipline in new tests

### Risks Introduced
- **Scope isolation in Pester v6** — Variables in `BeforeAll` not visible in `It` blocks without `$script:` scope
  - **Mitigation:** Use `$script:VariableName` for shared state; documented in testing standards

## Alternatives Rejected

Option 1 (stay on v5) rejected due to maintenance and compatibility concerns.
